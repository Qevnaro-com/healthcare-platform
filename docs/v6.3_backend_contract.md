# Pulse n Care — V6.3 Future Backend API Contract Specification

## 1. Authentication & Session Module (`/api/v1/auth`)

### 1.1 POST `/api/v1/auth/login`
* **Actor**: All Users (`client`, `organization`, `staff`, `admin`).
* **Input Payload**: `{ email: string, password: string }`.
* **Output Payload**: `{ token: string, user: User, role: UserRole }`.
* **Authorization**: Public endpoint.
* **Ownership Filter**: None.
* **Mutation**: Issues JWT session token & records `lastLoginAt`.
* **Error Cases**: `401 Unauthorized` (Invalid credentials), `403 Forbidden` (Account disabled).

### 1.2 GET `/api/v1/auth/me`
* **Actor**: Authenticated User.
* **Input Payload**: None (Headers: `Authorization: Bearer <token>`).
* **Output Payload**: `{ user: User, profile: ClientProfile | StaffProfile | OrganizationProfile }`.
* **Authorization**: Bearer Token required.
* **Ownership Filter**: Self user record matching token sub.
* **Mutation**: Read-only.
* **Error Cases**: `401 Unauthorized` (Token expired/invalid).

## 2. B2C Client Module (`/api/v1/client`)

### 2.1 GET `/api/v1/client/services`
* **Actor**: Public / B2C Client.
* **Input Payload**: Query parameters: `?category=home_nursing`.
* **Output Payload**: `{ services: Service[] }`.
* **Authorization**: Public.
* **Ownership Filter**: None.
* **Mutation**: Read-only catalog query.
* **Error Cases**: None.

### 2.2 POST `/api/v1/client/care-requests`
* **Actor**: B2C Client (`client`).
* **Input Payload**: `{ patientId: string, addressId: string, serviceId: string, scheduledDate: string, shiftType: string, careTasks: string[], specialInstructions?: string }`.
* **Output Payload**: `{ booking: Booking }`.
* **Authorization**: Role `client`.
* **Ownership Filter**: Checks `patientId.clientId === currentUserId` & `addressId.clientId === currentUserId`.
* **Mutation**: Inserts `CARE_REQUEST` (`Booking`) record in status `REQUESTED`.
* **Error Cases**: `400 Validation Error`, `403 Forbidden` (Patient or Address not owned by client).

### 2.3 GET `/api/v1/client/care-requests`
* **Actor**: B2C Client (`client`).
* **Input Payload**: Query parameters: `?status=all`.
* **Output Payload**: `{ bookings: Booking[] }`.
* **Authorization**: Role `client`.
* **Ownership Filter**: Strictly filtered by `clientId === currentUserId`.
* **Mutation**: Read-only.
* **Error Cases**: `401 Unauthorized`.

### 2.4 GET `/api/v1/client/care-requests/:id`
* **Actor**: B2C Client (`client`).
* **Input Payload**: URL parameter `:id`.
* **Output Payload**: `{ booking: Booking }`.
* **Authorization**: Role `client`.
* **Ownership Filter**: Strictly enforces `booking.clientId === currentUserId`.
* **Mutation**: Read-only.
* **Error Cases**: `404 Not Found`, `403 Forbidden` (Belongs to another client).

## 3. Institutional B2B Organization Module (`/api/v1/organization`)

### 3.1 GET `/api/v1/organization/profile`
* **Actor**: Organization User (`organization`).
* **Input Payload**: None.
* **Output Payload**: `{ organization: B2BOrganization, facilities: OrganizationFacilityLocation[] }`.
* **Authorization**: Role `organization`.
* **Ownership Filter**: `organizationId === currentOrgId`.
* **Mutation**: Read-only.
* **Error Cases**: `401 Unauthorized`, `403 Forbidden`.

### 3.2 POST `/api/v1/organization/staffing-requests`
* **Actor**: Organization User (`organization`).
* **Input Payload**: `{ facilityLocation: OrganizationFacilityLocation, contactPerson: OrganizationContactPerson, startDate: string, endDate: string, contractType: string, requirements: StaffingRequirementLine[] }`.
* **Output Payload**: `{ staffingRequest: OrganizationStaffingRequest }`.
* **Authorization**: Role `organization`.
* **Ownership Filter**: Sets `organizationId = currentOrgId`.
* **Mutation**: Inserts B2B staffing request in status `submitted`.
* **Error Cases**: `400 Validation Error` (Empty requirements array), `403 Forbidden`.

### 3.3 GET `/api/v1/organization/staffing-requests`
* **Actor**: Organization User (`organization`).
* **Input Payload**: None.
* **Output Payload**: `{ staffingRequests: OrganizationStaffingRequest[] }`.
* **Authorization**: Role `organization`.
* **Ownership Filter**: Strictly filtered by `organizationId === currentOrgId`.
* **Mutation**: Read-only.
* **Error Cases**: `401 Unauthorized`.

### 3.4 GET `/api/v1/organization/roster`
* **Actor**: Organization User (`organization`).
* **Input Payload**: Query parameters: `?startDate=2026-09-01&endDate=2026-09-30`.
* **Output Payload**: `{ rosterSlots: FacilityShiftRosterSlot[] }`.
* **Authorization**: Role `organization`.
* **Ownership Filter**: Strictly filtered by `organizationId === currentOrgId`.
* **Mutation**: Read-only.
* **Error Cases**: `401 Unauthorized`.

## 4. Admin Operations Module (`/api/v1/admin`)

### 4.1 GET `/api/v1/admin/queues`
* **Actor**: Admin (`admin`, `super_admin`).
* **Input Payload**: Query parameters: `?stream=b2c|b2b`.
* **Output Payload**: `{ b2cRequests: Booking[], b2bRequests: OrganizationStaffingRequest[] }`.
* **Authorization**: Role `admin`.
* **Ownership Filter**: Unrestricted operational view across all clients and organizations.
* **Mutation**: Read-only.
* **Error Cases**: `403 Forbidden`.

### 4.2 POST `/api/v1/admin/assignments`
* **Actor**: Admin (`admin`).
* **Input Payload**: `{ targetStream: 'b2c' | 'b2b', targetId: string, requirementLineId?: string, staffId: string }`.
* **Output Payload**: `{ assignment: Assignment, duty: Duty }`.
* **Authorization**: Role `admin`.
* **Ownership Filter**: None.
* **Mutation**: Updates request status to `ASSIGNED` / `PARTIALLY_ASSIGNED` and creates new `Duty` for assigned staff.
* **Error Cases**: `409 Conflict` (Staff unavailable or rest period violation), `404 Not Found`.

---

## 5. Staff Duty Portal Module (`/api/v1/staff`)

### 5.1 GET `/api/v1/staff/duties`
* **Actor**: In-House Staff (`staff`).
* **Input Payload**: Query parameters: `?status=active|history`.
* **Output Payload**: `{ duties: Duty[] }`.
* **Authorization**: Role `staff`.
* **Ownership Filter**: Strictly filtered by `staffId === currentStaffId`.
* **Mutation**: Read-only.
* **Error Cases**: `401 Unauthorized`.

### 5.2 PATCH `/api/v1/staff/duties/:id/transition`
* **Actor**: In-House Staff (`staff`).
* **Input Payload**: `{ nextStatus: DutyStatus, notes?: string, vitals?: VitalsEntry }`.
* **Output Payload**: `{ duty: Duty }`.
* **Authorization**: Role `staff`.
* **Ownership Filter**: Strictly filtered by `duty.staffId === currentStaffId`.
* **Mutation**: Transitions state per strict state machine matrix (`ASSIGNED` → `EN_ROUTE` → `ON_DUTY` → `COMPLETED`).
* **Error Cases**: `400 Bad Request` (Invalid backward transition attempt), `403 Forbidden` (Not assigned staff).
