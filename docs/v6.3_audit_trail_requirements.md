# Pulse n Care — V6.3 Audit Trail & Lifecycle Tracking Requirements

## 1. Audit Trail Overview

In healthcare operations, regulatory compliance, dispute resolution, clinical liability, and institutional billing require immutable audit trails. Every status change, assignment change, and financial transaction must record an audit entry.

---

## 3. Required Persistence Audit Schema

When connected to a production database, audit entries MUST be stored in an append-only table (`audit_logs`) structured as follows:

```typescript
export interface AuditLogEntry {
  id: string;                      // UUID
  timestamp: string;               // ISO 8601 UTC
  eventType: string;               // e.g. 'duty.clock_in.timestamp'
  actorId: string;                 // User ID or Staff ID
  actorRole: 'client' | 'organization' | 'staff' | 'admin' | 'system';
  targetEntityType: 'booking' | 'staffing_request' | 'duty' | 'timesheet' | 'invoice';
  targetEntityId: string;          // Target record ID
  organizationId?: string;         // Scoped tenant ID for B2B events
  previousState?: Record<string, any>;
  newState?: Record<string, any>;
  ipAddress?: string;
  userAgent?: string;
  notes?: string;
}
```
